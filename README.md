# What is it?
It is a WiFi Deauthenticator based on an ESP8266(Wemos D1 Mini) and its ability to send user-defined 802.11 packets with the "wifi_send_pkt_freedom" function.
An old firmware has to be used because it is not available in current versions.


# Additional information
It can only be used to perpetrate deauthentication attacks on networks that operate on 2.4 GHz as its WiFi module can't use the 5 GHz band.
